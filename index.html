⩩﹕rules 📋﹒ Chess Rules & Project Overview

Piece Movement

  • Pawn: Moves 1 square forward (or 2 on start). Captures diagonally. Supports En Passant and Pawn Promotion.
  • Knight: Moves in an 'L' shape (2 squares in one direction, 1 perpendicular). Jumps over other pieces.
  • Bishop: Moves diagonally any distance.
  • Rook: Moves horizontally or vertically any distance.
  • Queen: Combines rook and bishop movements in all 8 directions.
  • King: Moves 1 square in any direction. Supports Castling with unmoved rooks.

Project Architecture

Features an intelligent game agent with:

  • Minimax Algorithm with Alpha-Beta Pruning: Deep recursive move tree search.
  • Piece-Square Positional Tables (PST): Dynamic heuristic evaluation.
  • MVV-LVA Move Ordering: Alpha-beta cutoff acceleration.
